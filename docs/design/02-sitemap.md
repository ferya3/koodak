# ۲. نقشه‌ی سایت (Sitemap)

وضعیت: ✅ پیاده‌سازی‌شده در `apps/web` · 🔜 فاز بعد

```
/                                   ✅ صفحه‌ی اصلی (Hero، انتخاب سن، ۱۰ دنیا، محبوب‌ها، والدین، امنیت، FAQ)
├── /worksheets                     ✅ کتابخانه‌ی کاربرگ (جستجو، فیلتر سن/نوع/سطح/رایگان)
│   └── /worksheets/[slug]          ✅ پیش‌نمایش A4، چاپ، دانلود PNG/SVG، کاربرگ‌های مشابه، JSON-LD
├── /games                          ✅ فهرست بازی‌ها + «به‌زودی»
│   └── /games/[slug]               ✅ اجرای بازی (GamePlayer) + اطلاعات والدین
├── /stories                        ✅ دنیای قصه
│   └── /stories/[slug]             ✅ قصه‌خوان تعاملی (صوت، اندازه‌ی متن، نشانک، انتخاب مسیر)
├── /learn/[category]/[subject]     🔜 آکادمی یادگیری (درس‌ها)
├── /discover/[topic]               🔜 دنیای کشف
├── /blog                           🔜 مقالات آموزشی والدین
├── /pricing                        ✅ اشتراک‌ها (رایگان / خانواده / مدرسه)
├── /privacy                        ✅ حریم خصوصی کودکان + قوانین + تماس
├── /design-system                  ✅ مستند زنده‌ی سیستم طراحی (noindex)
├── /auth/(login|register|reset)    🔜 احراز هویت والدین
│
├── /kids                           ✅ «کی داره بازی می‌کنه؟» (noindex)
│   ├── /kids/home                  ✅ داشبورد کودک: سلام، مأموریت روزانه، پیشنهاد پیکو، دنیاها، مدال‌ها
│   ├── /kids/play/[slug]           ✅ بازی (مراحل به ترتیب باز می‌شوند)
│   ├── /kids/story/[slug]          ✅ قصه
│   ├── /kids/studio                ✅ استودیو نقاشی
│   └── /kids/world/[slug]          🔜 صفحه‌ی اختصاصی هر دنیا
│
├── /parent                         ✅ داشبورد والدین (KPI، زمان روزانه، تفکیک فعالیت، مهارت‌ها، پیشنهاد، تاریخچه)
│   ├── /parent/reports             ✅ گزارش‌های PDF
│   ├── /parent/settings            ✅ زمان، قفل خواب، محتوای مجاز، حریم خصوصی، حذف داده
│   ├── /parent/children/new        🔜 افزودن فرزند (نام نمایشی + سال/ماه تولد + آواتار)
│   └── /parent/billing             🔜 مدیریت اشتراک و پرداخت
│
├── /teacher                        🔜 پرتال مربی (کلاس، تکلیف، گزارش کلاس)
└── /admin                          🔜 Filament (Laravel) – خارج از این اپ
```

## قواعد SEO
- فقط صفحات عمومی در `sitemap.xml` هستند. `/kids`, `/parent` با `robots.txt`، متادیتای `noindex` و هدر `X-Robots-Tag` بسته شده‌اند.
- هر صفحه‌ی محتوا: `canonical`، Open Graph، و JSON-LD (`LearningResource` برای کاربرگ، `FAQPage` برای خانه).

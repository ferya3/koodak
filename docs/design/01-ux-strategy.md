# ۱. استراتژی UX محصول KidsWorld

## کاربران و نقش‌ها

| کاربر | هدف اصلی | نگرانی اصلی | محیط |
|---|---|---|---|
| **کودک ۲–۴ ساله** (پیش‌خوان) | لذت، لمس، صدا | گم شدن، شکست | محیط کودک – فقط تصویر و صدا |
| **کودک ۵–۷ ساله** (نوخوان) | چالش، ستاره، مدال | سختی بیش از حد | محیط کودک – تصویر + کلمه‌های کوتاه |
| **کودک ۸–۱۰ ساله** (خواننده) | پیشرفت، استقلال | کودکانه بودن بیش از حد | محیط کودک – سطح «پیشرفته»، متن بیشتر |
| **والد** | آرامش خاطر، دیدن رشد، کاربرگ سریع | امنیت، زمان صفحه، تبلیغ | سایت عمومی + پنل والدین |
| **مربی / مدرسه** | مدیریت کلاس، تکلیف، گزارش | زمان آماده‌سازی | پرتال مربی (فاز ۶) |
| **مدیر محتوا** | انتشار سریع و بدون کدنویسی | کیفیت، تأیید | Admin (Filament) |

## اصول تجربه (Experience Principles)

1. **تصویر قبل از متن.** هر عمل اصلی در محیط کودک یک آیکون تصویرسازی‌شده، یک رنگ ثابت و (در آینده) یک راهنمای صوتی دارد.
2. **هیچ بن‌بستی وجود ندارد.** کودک هرگز به صفحه‌ی خطا، فرم یا لینک بیرونی نمی‌رسد. دنیاهای بدون محتوا «به‌زودی» نمایش داده می‌شوند، نه لینک شکسته.
3. **شکست، بخشی از بازی است.** پاسخ نادرست = لرزش ملایم + «دوباره امتحان کن»؛ هیچ صدای خشن، رنگ قرمز ترسناک یا از دست دادن امتیاز.
4. **پاداش برای تلاش، نه فقط نتیجه.** حداقل ۱ ستاره برای پایان هر مرحله؛ ۳ ستاره برای دقت.
5. **والدین کنترل دارند، نه نظارت پنهان.** همه‌ی داده‌ها قابل مشاهده، دانلود و حذف است. گزارش‌ها «مشاهده‌ی تمرین» هستند، نه برچسب استعداد.
6. **سه محیط متمایز.** سایت عمومی (شاد و قابل اعتماد) ≠ محیط کودک (بازیگوش و درشت) ≠ پنل والدین (آرام و داده‌محور).

## دروازه‌ی والدین (Parent Gate)

هر خروج از محیط کودک (پنل والدین، خرید، تنظیمات، لینک بیرونی) پشت یک سؤال ضرب **نوشتاری** است («هفت ضرب در شش») تا کودکِ پیش‌خوان نتواند تصادفی عبور کند.

## زمان صفحه

- سقف روزانه توسط والد تعیین می‌شود؛ ۵ دقیقه مانده، پیکو یادآوری می‌کند.
- پایان زمان: بازی ذخیره می‌شود و پیکو با انیمیشن «خواب‌آلود» خداحافظی می‌کند (نه قطع ناگهانی).
- قفل ساعت خواب: فقط قصه‌های قبل از خواب در دسترس.
